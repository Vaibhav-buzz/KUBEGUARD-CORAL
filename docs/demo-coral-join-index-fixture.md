# Demo Coral Join Index Fixture

This file is intentionally documentation-only.

It exists to create a visible pull request size signal for the KubeGuard demo without changing application runtime behavior, server behavior, source configuration, workflow logic, or production code.

When this branch is opened as a pull request, GitHub reports the added lines in this file. KubeGuard then uses that PR size as one of the inputs in the Coral join risk workflow.

Expected demo behavior:

- The PR appears in the Pull Requests section.
- The PR can be labelled with `service:payments`.
- The Coral join can score the PR with a visible size signal.
- Merging the PR does not alter application code.
